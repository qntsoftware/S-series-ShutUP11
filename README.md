# S-series-ShutUP11
ShutUp11, Windows 11'in gizlilik ihlallerini engelleyen, gereksiz arka plan servislerini durduran ve sistem performansını zirveye taşıyan açık kaynaklı bir kontrol merkezidir. Terminatör Modu ile CPU/GPU ve ağ kullanımınızı optimize ederek oyunlarda maksimum FPS almanızı sağlar. Güvenli, şık ve tek tıkla tam kontrol sunan nihai sistem aracıdır.
